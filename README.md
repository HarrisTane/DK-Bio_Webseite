# DK Bio

Statischer Produktkatalog auf Deutsch, Französisch und Englisch.

## Lokale Vorschau

Im Repository `python3 -m http.server 8000` starten und `http://localhost:8000` öffnen.

## GitHub Pages

Die Website liegt im Stammverzeichnis von `main`. In **Settings → Pages** als Quelle **Deploy from a branch** mit **main / (root)** verwenden.
